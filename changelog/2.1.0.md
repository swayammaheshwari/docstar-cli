# 2.1.0

## New features

- `docstar-cli setup <slug>` sets up a collection everywhere in one command, e.g. `npx docstar-cli setup msg91`:
  installs docstar-cli (`npm install -g`, when run through npx), registers every module with its `<slug>` shortcut,
  adds the collection's hosted MCP server (`https://mcp.docstar.io/connector/<slug>`) to Claude Code, Cursor, Codex,
  OpenCode, GitHub Copilot CLI and Factory Droid where they are installed, adds a `<slug>-api` skill to the AI agents
  on the computer (through `npx skills add`), and signs in when the collection has a sign-in. An MCP entry already
  using the name is left as it is, a config file that isn't valid JSON is never rewritten, and an AI agent running it
  is never left waiting on a prompt. `--dry-run` shows what would change; `--mcp-url` gives the MCP URL when it is the
  owner's own domain; `--skip-install`, `--skip-init`, `--skip-mcp`, `--skip-skill` and `--no-login` skip a step.
- `init --all` registers every module without the checklist, so it works from a script.
- `setup` is now a reserved slug (keep in line with hitman-api's `utils/slug.js`).
