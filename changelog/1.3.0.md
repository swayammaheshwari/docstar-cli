# 1.3.0

## New features

- Header values configured in the docs editor (e.g. `authkey`) are now exposed as CLI flags on
  generated commands, the same way `cli.parameters` are — e.g. `docstar-cli msg91 whatsapp
  send-message-in-text --authkey <value>`. Previously these were baked into the cached module
  JSON with no supported way to override them from the CLI, so requests kept sending whatever
  placeholder/value was cached (see `requirement/header-values-not-settable-via-cli.md`).
- **`docstar-cli config set <cliName> <key> <value>`**: save a per-collection credential (e.g. an
  API/auth key) once so it's injected into every request automatically, instead of having to pass
  it as a flag every time. An explicit `--<key> value` flag on a command still overrides the saved
  credential.
