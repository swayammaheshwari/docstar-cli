# 1.9.0

## New features

- Each installed collection gets its own command: after `docstar-cli init msg91`, run
  `msg91 <module> <endpoint>` instead of `docstar-cli msg91 <module> <endpoint>`. It is a small launcher
  that forwards to `docstar-cli msg91 ...`, so the collection → module → endpoint hierarchy is unchanged.
  - Created next to `docstar-cli` (or in another writable PATH directory); if none is writable it goes in
    `~/.docstar/bin` and `init` tells you to add that to your PATH.
  - It never replaces an existing command that isn't one of ours (e.g. a collection named `git`).
  - `init --no-alias` skips it. `clean <collection> --all` (or removing its last module) deletes it.
- `alias <collection>` creates the command for collections installed earlier; `alias <collection> --remove` deletes it.

## Changed

- `init` also refuses the slug `alias` (now a CLI command). Kept in line with hitman-api's `RESERVED_SLUGS`.
