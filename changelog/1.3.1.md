# 1.3.1

## Fixes

- Fixed request bodies dropping object-valued parameters as raw JSON strings instead of parsed
  objects (e.g. `whatsapp send-message`'s `payload` parameter), which caused APIs expecting a
  JSON object to reject the request. `coerceToTemplateType` in `src/lib/http.ts` now parses the
  CLI-supplied string back into an object when the body template's existing value for that key is
  itself an object, mirroring the existing array-handling fallback.
