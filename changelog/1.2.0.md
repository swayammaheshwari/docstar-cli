# 1.2.0

## New features

- **`docstar-cli clean <collection>`**: uninstall modules from an installed collection, or the
  entire collection.
  - Bare form shows an interactive checklist of the collection's installed modules (nothing
    checked by default, with a "Select all modules" entry), matching `init`'s picker UX. Removes
    each selected module's saved contract, generated commands, and config entry; if the
    collection ends up with zero modules, its config entry and module directory are removed
    entirely.
  - `--all` removes the whole collection in one step, prompting for confirmation first unless
    `--force` is also passed.

## Fixes

- Re-applied the generated-command escaping fix in `codegen.ts` (parameter names are now embedded
  via `JSON.stringify` instead of raw string interpolation) after it was found reverted on disk.
