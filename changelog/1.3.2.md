# 1.3.2

## Fixes

- Fixed dynamically-generated commands (created by `init` after install, e.g.
  `docstar-cli clitest whatsapp new-whatsapp`) reporting "command not found" on an npm-installed
  copy of the CLI. The published package previously bundled a static `oclif.manifest.json` (baked
  by `prepack`'s `oclif manifest` step), which oclif trusts as the authoritative command list
  instead of scanning `dist/commands` on disk — so any command file written after install was
  invisible to oclif even though it existed. `oclif manifest` generation has been removed from
  `prepack`, and `oclif.manifest.json` is no longer listed in `files`, so oclif always resolves
  commands by scanning `dist/commands`, both in local development and in installed packages.
