# 1.2.1

## Fixes

- `--version`/`-v` now prints only the bare version number (e.g. `1.2.1`) instead of oclif's
  default `docstar-cli/1.2.1 darwin-arm64 node-v22.22.3` line. Handled in `bin/run.js`, which
  intercepts the flag before oclif's own version handling runs.
- Removed the unused `@oclif/plugin-plugins` dependency and its `plugins` command/topic — this CLI
  never used plugin management, and it was cluttering `docstar-cli --help` with a duplicate
  `plugins` row and an empty `TOPICS` section.
