# 2.0.0

## New features

- Every collection works without `init`: `docstar-cli msg91 sms send-sms` reads the module's contract from the
  docs when it runs, asks for anything missing, and calls the API. `docstar-cli msg91` lists the modules,
  `docstar-cli msg91 sms` the endpoints of a module, and `--help` on an endpoint its flags. Root endpoints work the
  same way (`docstar-cli msg91 <endpoint>`).
- One endpoint per hit: a command reads just that endpoint's `module.json` (`/<module>/<endpoint>/module.json`, about 2 KB
  instead of 16-70 KB for the whole module). `module.json` is now a tree: the collection's modules, a module's list of
  endpoints (names and parameters only, no endpoint data), and one endpoint's full contract. The server finds the endpoint
  by its page path or by the command name or alias, so no lookup request comes first.
- Optional query parameters now work as flags (`--startDate ...`); they are added to the URL when given.
- Docs edits show up on the next command: contracts are no longer saved, so they cannot go stale.
- The collection's sign-in header comes with module.json (`auth`, e.g. `proxy_auth_token`). An endpoint that sends it
  runs on your `login` token and, when you are not signed in, says to run `docstar-cli login <slug>`. A collection
  without sign-in never asks for it. Any other enabled header with no value is asked for as it is (flag, prompt or
  `config set`).
- `config set`, `key save` and the "save it?" prompt work for a collection you never ran `init` for.
- `list <collection> [module]` works for any collection, not only registered ones.

## Changed (breaking)

- `init` only registers: the chosen modules and their command names go in `~/.docstar/config.json`, along with the
  `<slug>` shortcut, shell completion and MCP tools. It no longer saves contracts or generates command files, and
  removes the ones 1.x left (`~/.docstar/modules/<slug>`, `dist/commands/<slug>`).
- Every command, and `mcp` when it starts, needs network access to read the docs. `mcp` skips (with a warning) a
  module it cannot read. Shell completion offers only registered modules and commands, and never calls the network.
- `docstar-cli <word> ...` now treats any word that is not one of the CLI's own commands as a collection slug.

## Bug fixes

- `init` for a collection you already registered no longer drops the API keys saved for it.
- An endpoint with an `Authorization` header no longer demands `login` from a collection that has no sign-in.
