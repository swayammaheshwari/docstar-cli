# 1.5.0

## New features

- `init` now picks up **root endpoints**: endpoints that sit directly at the collection root,
  outside every module. `GET /p/module.json` returns them as `rootEndpoints`, and
  `GET /p/module.json?scope=root` returns their full contracts. They show up as a
  "Root endpoints" choice in the `init` checklist (and in "Select all").
- Root endpoints are the one two-level form: the shell command is
  `docstar-cli <collection> <endpoint>` and the MCP tool is `<collection>__<endpoint>`.
  They are stored locally as the pseudo-module `__root__`
  (`~/.docstar/modules/<collection>/__root__.json`); `list <collection> __root__` lists them and
  `clean` removes them.
- A root endpoint whose command name equals an installed module's name is skipped with a warning,
  since it would shadow that module's topic.
