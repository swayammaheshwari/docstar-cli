# 1.6.0

## New features

- `key pull <code> [--env .env] [--api <url>]`: picks up the API keys (and other values, such as a
  secret or a project id) that a DocStar MCP server created for the signed-in user (its API key
  tool returns this command with a one-time code) and writes them to the project's env file, one
  variable each. Other lines are kept, the file is made readable by its owner only and added to
  `.gitignore`, and only each value's last 4 characters are printed, so no value reaches the AI
  assistant reading the output. Calls `POST /p/mcp-api-key/pull` on the
  DocStar API (default `https://api.docstar.io`).
