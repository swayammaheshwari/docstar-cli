# 1.6.0

## New features

- `key pull <code> [--env .env] [--api <url>]`: picks up an API key that a DocStar MCP server
  created for the signed-in user (its API key tool returns this command with a one-time code)
  and writes it to the project's env file. Other lines are kept, the file is made readable by its
  owner only and added to `.gitignore`, and only the key's last 4 characters are printed, so the
  key never reaches the AI assistant reading the output. Calls `POST /p/mcp-api-key/pull` on the
  DocStar API (default `https://api.docstar.io`).
